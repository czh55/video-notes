内容要点

明度就是色彩的明亮程度。可以简单地理解为颜色的深浅变化。比如，在无彩色中，白色是明度最高的，黑色则是明度最低的。在色彩加入白色（图中向上的变化），你会发现色彩明显变亮了；如果加入黑色（向下的变化），那你会发现色彩变暗了，这就是色彩明度（亮度）的变化。 🌈明度的变化对色彩的影响： 👉当我们提高某种颜色的明度时（比如通过加白色），这个颜色会看起来更亮、更轻盈，给人一种清新、活泼的感觉。 👉反之，如果降低颜色的明度（比如加黑色），颜色会变得更深沉、厚重。
