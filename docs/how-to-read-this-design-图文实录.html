扭在一起的造型常被问「什么意思」：留意古典椅子或螺旋柱（口播「黏蓝丹」宜作螺旋柱/Solomonic column 理解），会发现异常相像——设计灵感来源于此。

00:46-01:31对称版式与角标规则化

版式上也偏中心对称或比较对称，对称会传达古典感受；看一张不对称对照就明白。最细节的是：九宫格雕像左下角都有小标——不仅是编号，也能让不够规则的图形变得规则。
