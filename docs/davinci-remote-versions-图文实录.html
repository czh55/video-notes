00:00–00:22什么是达芬奇的远程版本?

什么是达芬奇的远程版本?；通俗讲解,远程版本就是达芬奇里全局同步的调色版本；只要是同一个原始素材,不管放在多少条时间线、多少个位置；用了同一个远程版本,改一处,全部同步变；怎么做呢?很简单；先选中一段素材,右键找到调色版本、远程版本

00:23–00:46创建新版本,给它起个名字,比如统一风格

创建新版本,给它起个名字,比如统一风格；然后你正常调色,调完之后；你再把这个素材拖到时间线上别的位置,甚至别的时间线；右键它同样找到远程版本,选中你刚才创建的统一风格；这时候你会发现颜色自动同步了；你再回去改第一个片段

00:45–00:59后面所有用了这个远程版本的素材全部一起跟着变

后面所有用了这个远程版本的素材全部一起跟着变；它特别适合什么场景；比如你一个镜头要反复用,或者全片要统一色调；批量调色,团队协作的时候,远程版本最省事
