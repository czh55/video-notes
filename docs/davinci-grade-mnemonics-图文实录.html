达芬奇调色怎么调？记住这几个口诀！

调色 · 原文短链

按这张图，调色的顺序是先把画面调对，再谈好不好看。先还原曝光和对比，高光不爆、暗部不死，肤色保持自然、不偏绿也不偏紫。要立体感，就把暗部偏冷、高光偏暖。节点少一点：串行做校正，并行做局部，图层做叠加。眼睛会被环境光骗，波形图和矢量图才是色彩安全的底线。风格化放在最后。整页收成一句：先校正，后风格；先准，再美。

一张图上的七句口诀

背景是虚化的调色界面，能看见色轮、波形和节点一类的界面残影，四周有胶片条装饰。正文是七个编号色块，每块一句口诀、一句解释，右侧配小图。这不是操作录屏，没有点哪个面板、拉多少数值。

口诀一写着「先校正，后风格」，下面是「先还原曝光与对比，再做风格化。」旁边是两条横向滑杆。它把顺序定死：曝光和对比先回到能看的状态，风格化不能抢在还原前面。

口诀二是「高光柔，暗部沉」，解释为「高光不爆，暗部不死，保留细节。」意思是高光略收、暗部留住层次，两边都不要裁成纯白或纯黑。色块右侧有一条明暗滑杆，滑杆上的小字读不清，标为无法确认。

口诀三是「肤色准，冷暖稳」，解释为「肤色自然，不偏绿不偏紫。」旁边画着矢量示波器，并标出肤色线。冷暖可以动，但肤色被单独拎出来当底线，偏绿或偏紫都不算过关。

口诀四是「冷暖对比，画面立体」，解释为「暗部偏冷，高光偏暖，增强空间层次。」右侧色环上半偏暖、下半偏冷，和这句对应。这是在前三条已经把曝光、细节和肤色守住之后，才用冷暖拉开空间。

口诀五是「节点少，逻辑清」，解释为「串行校正，并行局部，图层叠加。」旁边是三个相连的节点小图。它只规定三类节点各管一件事，没有给快捷键，也没有画完整节点树。

口诀六是「看示波器，别信眼睛」，解释为「波形图、矢量图，才是色彩安全底线。」旁边是一扇波形窗口。眼睛在这里被明确降级：环境光会骗判断，安全范围要看波形和矢量。

口诀七是「风格化，放最后」，解释为「先解决对不对，再解决美不美。」旁边是两格胶片画幅。它和口诀一是同一条顺序的收尾：对不对先于美不美。

底栏灯泡旁写着「先校正，后风格；先准，再美。」最下一行是「多拉片，多练习，形成自己的手感。」图上没有示范片、没有前后对比，练习被留成一句劝告。

汇总结论

这张图回答「达芬奇调色怎么调」的办法，是一条检查顺序，不是一套参数。先还原曝光与对比，守住高光和暗部的细节，把肤色拉回不偏绿、不偏紫，再用暗部偏冷、高光偏暖做层次，节点按串行校正、并行局部、图层叠加来少而清楚，并用波形图、矢量图核对，风格化放到最后。

依据来自哪一页

  • 全部七句口诀、解释句和底栏两句，都在第 1/1 页。
  • 「先校正，后风格」出现两次：口诀一，以及底栏「先校正，后风格；先准，再美。」口诀七用「对不对 / 美不美」把同一顺序再说一遍。

边界

  • 这是笔记作者印在一张图上的看法，不是达芬奇官方流程，也不是对所有片种的定论。
  • 图上没有软件版本、没有滑块数值、没有示波器的具体刻度，不能当成可复现的操作步骤。
  • 口诀二右侧滑杆上的小字无法确认。口诀四的标题是美术字，按画面读作「冷暖对比，画面立体」，与下面那句「暗部偏冷，高光偏暖」一致。
  • 「多拉片，多练习」没有给出拉哪类片子、练到什么程度算手感形成。
